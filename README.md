# Immortal Pixel OTA releases

This public repository hosts signed GrapheneOS release assets for the Frankel device.

Each stable release includes the `frankel-stable` channel metadata generated by the pinned source tree and the matching `frankel-ota_update-<build>.zip` archive. Factory install artifacts and checksums may be attached to the same release when available.

OS signing keys and passphrases are kept in the private build vault and are never stored in this repository.
